# statik-cs25-log25
LOG-2 — аналитическая система и MVP дашборд на базе данных Olist E-Commerce. Исследует влияние сроков доставки на оценки клиентов (1–5★) с помощью робастной статистики (медиана, P90, корреляция Спирмена) и прогнозирует риск срыва доставки с помощью логистической регрессии. Включает симулятор задержек на Streamlit
